# Paxlet layers

Keep the learning curve progressive:

```text
Core
  Paxlet → identity → resource/action → run

Node
  resolver → grants → receipts → runtime

Network
  registry → discovery → federation → replication

Adaptive systems
  planning → organisms → evolution → healing
```

A junior developer should need only the first line to start. Taskand belongs near the bottom of this stack as a demonstration of what becomes possible when the layers are combined.
