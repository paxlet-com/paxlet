# Paxlet Core 0.1.0 bootstrap

This bootstrap turns the Paxlet idea into an executable contract:

- Core 0.1 draft specification and schemas;
- stable URN identity separated from URI locations;
- zero-runtime-dependency Python reference CLI;
- `init`, `verify`, `inspect`, `resolve`, `run`, `pack`;
- deterministic package digests and execution receipts;
- explicit permission declarations and opt-in secret passing;
- local registry and five examples;
- unit tests + external CLI conformance suite;
- Taskand extraction/mapping notes;
- Paxlet brand landing/assets extracted to dedicated web repo `www-paxlet-com`.

Known intentional gaps are tracked in `ROADMAP.md`.
